MediCore Hospital Management System

A hospital management system for patient workflows, structured records, and role-based access to sensitive data.

JavaSpring BootReact
MEDICORE / HMS
✚

Overview

MediCore organizes patient information, appointments, clinical workflows, and administrative operations in one system, with a React frontend talking to a Spring Boot API.

What it covers

  • Digital patient and operational records with a structured data model.
  • Role-based access, so each user sees only what their role allows.
  • Consistent, traceable records across hospital workflows.

Engineering focus

  • REST API design and backend structure.
  • Database design and constraints.
  • Authentication and authorization.
  • Testing and application security.

In active development. The repository shows the current state of the code.
