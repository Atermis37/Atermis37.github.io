Project

Nairobi Real Estate Valuation Model

A machine learning project that estimates Nairobi property prices from listing data, from scraping through to a usable app.

PythonPlaywrightPandasScikit-learnStreamlit
NAIROBI / REAL ESTATE
⌁

Overview

Nairobi has no public, clean dataset of property prices, so this project builds one and then models it. It covers the full pipeline, from collecting listings to presenting predictions in an app.

Pipeline

  • Collect listings with Playwright browser automation.
  • Clean and preprocess the data with Pandas.
  • Explore the data and engineer features that describe each property and its location.
  • Train and evaluate models in scikit-learn.
  • Serve predictions through a Streamlit app.

Limitations

Scraped listings show asking prices, not final sale prices, so any model trained on them inherits that seller-side bias. Treat predictions as an estimate of the market's asking level, not a transaction value.
